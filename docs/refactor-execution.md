## 实现内容

浏览器仅导入共享纯规则和 HTTP 契约，服务端不依赖 renderer、Tauri 或模拟 `window`。生产构建会检查实际打包依赖，拒绝退役实现进入产物。SQLite 仅保存本工具的偏好、预设、目标、历史索引与迁移记录；原生 Provider、模型和 MCP 文件仍是活动配置来源。

普通编辑、预设、导入、历史和备份恢复共用配置事务内核。每份计划绑定目标、实际路径和当前版本；再确认覆盖也不能跳过版本复核。缺失恢复点、中断状态不明、CLI 版本未验证或格式不受支持时，服务端限制写入。读取不触发原生数据迁移。普通不变保存不写文件。

`server.lock.sqlite` 在所选私有目录内持有服务生命周期锁，JSON 文件只用于发现与身份校验。原生目标锁位于 `/tmp/kimi-code-switch-target-locks-<uid>/`，按 canonical 路径派生名称，目录 `0700`、文件 `0600`；它不随 HOME、TMPDIR 或 `--data-dir` 分裂，不包含配置正文。SQLite 锁随持有进程退出释放，锁文件不通过陈旧判断删除。此机制只协调本工具；外部编辑器和官方进程仍通过提交前版本复核与写后验证处理。

私有数据迁移需要预览清单及匹配的 manifest hash。旧数据保留，延期模块数据归档，旧托管原生目录按原路径接管；旧版未完成保存/恢复日志继续阻止写入。旧版进程运行时不能开始同时写入。备份列表逐项诊断未知/损坏格式，保留下载，禁止未经验证的自动恢复；早期 v1 未捕获的项目 MCP 文件在恢复时保持当前内容。

官方登录由官方工具维护，本工具仅读取已固定契约的本地状态，并明确未作远端验证。Skills 提供发现、来源和覆盖诊断；Skills/Plugins 目录参与本地备份恢复。Plugins 不新增私有管理协议。用量洞察、WebDAV、订阅桥接及复制凭据轮换已退出运行链路。
