# 浏览器界面验证与截图

Web 界面从真实本地服务读取配置。旧版 `?ui-fixture=showcase` 桌面 fixture 和历史桌面截图不作为新界面验收依据；`docs/images/web-overview.png` 来自本次真实 Web 流程。

## 准备

使用临时 HOME、KIMI_CODE_HOME 和工具私有目录，准备合成 Provider、模型、MCP、AGENTS 及项目样本。样本不含真实 key、端点、姓名或日志。前端连接真实 HTTP API；测试必须核对最终原生文件，不能只看成功提示。

开发可使用 `npm run dev`；其中 `KIMI_DEV_DATA_DIR` 只隔离工具私有数据，仍需显式隔离原生目录。发行验证使用 `npm run build` 产物及 `npm run check:package`，另记录浏览器与系统版本。

## 检查矩阵

| 项目 | 需要记录的结果 |
| --- | --- |
| 浏览器 | Safari、Chrome 的实际版本及完成的核心流程 |
| 尺寸 | 1440×900、1024×768、768px 窄窗及 200% 缩放 |
| 主题与语言 | 浅色、深色、跟随系统；中文、英文以及其他语言的布局抽查 |
| 导航与目标 | 五个一级入口、偏好设置、当前原生目录和项目路径明确可见 |
| 编辑与保存 | 新增或修改资源 → 检查变更 → 应用 → 核对文件；其他资源草稿保留 |
| 失败与冲突 | 外部修改、损坏文件、权限不足、服务断开、鉴权失效、提交结果查询 |
| 恢复 | 创建备份、导入、查看恢复计划、显式应用、恢复总闸与结果核对 |
| 键盘 | 可到达主要操作，弹窗焦点限制与恢复正确，字段错误有可访问关联 |

检查列表与表单内容能滚动到末尾、长路径可阅读、按钮不会被缩放遮挡；只读和空配置应有不同说明。主题、语言保存必须显示真实成功或失败。下载只显示“已发起下载”，不声称已保存到浏览器不可确认的路径。

## 留存证据

- 每张截图记录浏览器、窗口尺寸、主题和合成样本来源；未执行的矩阵项写为未验证。
- 本次临时验收证据可放在 `output/refactor-qa/`。只有经过脱敏检查的稳定截图才复制到文档目录并在 README 引用。
- 旧桌面截图保留作历史资料，不在当前产品说明中复用。
- `npm run test:a11y` 运行 Web 组件测试；测试名称不代表完整浏览器无障碍审计，真实键盘和缩放结果另行记录。
